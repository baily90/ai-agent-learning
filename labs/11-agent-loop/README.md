# Lab 11 · Agent 核心循环

> 配套第 12+13 章。目标：观察 Agent 如何"自主规划多步任务"。

## 跑起来

```bash
cp .env.example .env      # 填 DeepSeek key
npm install
npm run ask "我的订单 20231001001 想退款，告诉我具体怎么做？"
```

你会看到 Agent 的完整决策链：**先查订单状态 → 再查退款规则 → 综合回答**，而不是一次性瞎答。

## 学什么

- **Agent = LLM + 工具 + 循环**：AI 决定调哪个工具 → 代码执行 → 结果传回 → 再决定下一步
- **多步任务**：复杂问题需要连续调用多个工具（这里 2 个，真实场景更多）
- `result.toolCalls`：能看到 Agent 调用了哪些工具、传了什么参数
- `isStepCount(10)`：多步任务要放宽步数限制

## 练什么（挑战）

**挑战 1：错误恢复**

把 `getOrder` 的 `execute` 改成偶尔抛错（比如 `if (Math.random() < 0.5) throw new Error("数据库连接失败")`），看 Agent 能否重试或换策略。

**挑战 2：更复杂的多步任务**

加第三个工具（比如"提交退款申请"），让任务变成 3 步：查订单 → 查规则 → 提交退款申请。观察 Agent 能否自主串起来。

**挑战 3：对应客服项目**

这就是客服系统里"用户说我要退款"时的完整 Agent 流程——先查订单、再查规则、最后引导操作。
