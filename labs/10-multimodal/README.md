# Lab 10 · 多模态（图片理解）

> 配套第 11 章。目标：让 AI "看图说话"。

## 跑起来

```bash
cp .env.example .env      # 填 DASHSCOPE_API_KEY（视觉模型在 DashScope）
npm install
npm run ask                                # 默认用一张网络图
npm run ask "https://picsum.photos/400/300" "图片里有什么？"
npm run ask "./你的图片.jpg" "这张图是什么商品？"   # 本地图片
```

## 学什么

- **多模态输入**：content 从"纯文本"变成"parts 数组"（文本 + 图片）
- 视觉模型和纯文本模型是两回事——DeepSeek 不支持视觉，所以要换 qwen-vl-max
- 图片两种传法：URL（省事）或 base64（本地文件/隐私）

## 练什么（挑战）

**挑战 1：对应客服场景**

客服里多模态的典型用法：用户发一张商品破损的照片，AI 判断"这是质量问题还是人为损坏"。试试传一张商品图，让 AI 判断。

**挑战 2：图片 + 文字结合**

传一张图 + 问一个需要"看图 + 推理"的问题（比如"这张商品图适合什么人群"），感受多模态的推理能力。
