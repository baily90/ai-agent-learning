# Lab 09 · RAG 进阶

> 配套第 10 章。目标：理解 RAG 的三个进阶技巧——分块、混合检索、重排。

## 跑起来

```bash
cp .env.example .env      # 填 DeepSeek + 硅基流动 SiliconFlow 两个 key
npm install
npm run ask "我买的东西有质量问题，想换货怎么办？"
```

## 学什么

- **分块**：长文档不能整篇塞进向量库（检索会不精准），要切成小块
- **混合检索**：纯向量检索会漏掉"精确关键词"，加上关键词检索互补（向量 + 关键词）
- **重排**：多个分数加权综合，把最相关的排前面

## 练什么（挑战）

**挑战 1：去掉关键词分**

把 `total` 的计算改成只 `s.vectorScore`（纯向量检索），对比检索结果有什么变化——你就能直观看到"混合检索"的价值。

**挑战 2：调整分块策略**

把 `chunkByParagraph` 改成"按固定 20 字切块"，观察切得太碎会导致什么（语义被切断、检索变差）。

**挑战 3：真正的重排模型**

现在是用简单规则加权。真实项目会用 rerank 模型（如 bge-reranker）做重排。去查查 rerank 是什么，它跟 embedding 的区别是什么。
